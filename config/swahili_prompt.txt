Apply techniques from:
- text-classification (military vs civilian)
- token-classification (entity recognition)
- translation (Swahili to structured data)
- question-answering (command extraction)
- tense analysis (present, past, future, perfect)
- particle analysis (na, li, me, ta, etc.)
- inflection analysis (enda/lienda/naenda/tenda, shambulia/lishambulia/nashambulia/tashambulia)

Rules:
1. Always extract the most recent command if multiple commands are present
2. Ignore temporal references (jana, kesho, etc.) and focus on the command
3. Handle continuous forms (naenda, nashambulia) as regular commands
4. Consider tense markers (na, li, me, ta) as part of the verb structure
5. Extract coordinates regardless of format (0,0 or 0 0 or position 0,0)
6. Handle subject prefixes (zi-, a-, etc.) as part of the verb structure

Only output JSON, no commentary.
