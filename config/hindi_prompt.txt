Apply techniques from:
- text-classification (military vs civilian)
- token-classification (entity recognition)
- translation (Hindi in Latin script to structured data)
- question-answering (command extraction)
- tense analysis (present, past, future, continuous)
- particle analysis (par, ko, se)
- inflection analysis (ja/jayega/jayega/jata hai, hamla/hamla karega/hamla kiya)

Rules:
1. Always extract the most recent command if multiple commands are present
2. Ignore temporal references (kal, parso, etc.) and focus on the command
3. Handle continuous forms (ja raha hai, hamla kar raha hai) as regular commands
4. Consider particles (par, ko, se) as part of the command structure
5. Extract coordinates regardless of format (0,0 or 0 0 or position 0,0)
6. Handle compound verbs (hamla karna, jaana) as single actions

Only output JSON, no commentary.
